# 公开版验证范围

本页描述仓库初版在 2026-11-10 的实际检查。制作新书时仍须检查本次成品；不把脚本检查写成教学效果验证。

## 文件与安装

- `SKILL.md` 的名称、前置元数据和结构由 skill-creator 的校验器检查。
- 安装脚本在隔离的 Skills 目录实跑，检查文件复制、资源完整、已有技能内容保留、拒绝嵌套安装和不完整来源；不覆盖维护者本机已安装版本。
- 两动作小样由公开版脚本从自带素材构建：恐龙跑步、跳远，简洁和公园两场景。
- `book.py verify` 回读单文件 HTML、文件夹、ZIP，核对 ZIP CRC、成员和资源字节；动画解码全部帧，核对透明角、时长、非静态和一次播放标记。
- 未随仓库公开维护者的历史验收日志、账号、配置、私有运行时或本机绝对项目路径。

## PPTX 与未验证项目

PPT 构建脚本随技能公开，仍依赖宿主的 presentations 技能和 Artifact Tool。本仓库不包含这些组件。本次公开打包的安装与浏览器小样检查，不能证明每位老师的环境已具备 PPT 导出能力。

本次未重新执行 PowerPoint 全书放映、WPS、真实手机、课堂/儿童使用或临床效果测试。请在实际使用端验证动作播放、翻页和跳转。README 中的“一句话”指输入需求的方式，不承诺无需依赖、即时生成或所有播放器一致。
